# Job detail matching addition

## Direction contract

THESIS: Help an applicant inspect evidence before applying, not judge them with a
decorative score. Operate mode, scoped to a section inside the existing job detail.

OWN-WORLD: Preserve the existing light surfaces, teal primary control, inherited
typography and spacing tokens. Use plain stacked requirement rows, not nested cards.

STORY: Click Analyze my match, read the limitations, compare the two quoted sources,
then update profile details or proceed with their own application decision.

FIRST VIEWPORT: The section follows the job header and precedes the description.
One heading, short scope note, analysis button and profile link are visible before
interaction. Results stay inline, ordered by exact skill entries, partial shared
mentions with conditions unverified, explicit gaps, then remaining unknowns.

FORM: Local extension of an established surface; no concept seed or replacement
visual world. Code-led; no new raster assets. Evidence disclosure is the signature.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Existing DESIGN.md is absent; this narrow extension does not establish or replace
a global design system. Review evidence and code tokens instead. No matching score,
paid model call, new database table, automatic application or ranking is in scope.
