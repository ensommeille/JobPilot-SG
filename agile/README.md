# Agile artifacts — JobPilot SG

This folder holds the course's agile process evidence (SWE5006 deliverable).

## Conventions

| Artifact | Where | How |
|---|---|---|
| Product backlog | `product-backlog.md` | Prioritised list; P0 = must, P1 = should, P2 = stretch |
| User stories | GitHub Issues | One story = one issue (template: `.github/ISSUE_TEMPLATE/user_story.md`) |
| Sprint plan | `sprint-XX-plan.md` | Created at sprint start: stories chosen, goal, owners |
| Sprint review | `sprint-XX-review.md` | At sprint end: what was demoed, feedback |
| Retrospective | `sprint-XX-retro.md` | What went well / to improve / action items |
| Burndown | `sprint-XX-burndown.png` (or .md) | Derived from issue closure counts, updated ~daily |
| Milestones | GitHub Milestones | One milestone per sprint, issues attached |

## Sprint rhythm

- Sprint length: 2 weeks (see development document §15 for the iteration plan).
- Every sprint ends with a runnable integrated version (tag it: `sprint-N`).
- Fill sprint review/retro within 24h of sprint end — do not backfill later.
